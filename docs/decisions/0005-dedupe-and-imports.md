# 0005 — ربط الكيانات وإزالة التكرار والاستيراد

التاريخ: 2026-09-22 · الحالة: معتمد · F-005، SPEC §6.3

## قوة المعرفات

| المعرف | القوة | ملاحظة |
|---|---|---|
| النطاق (بعد إزالة www) | قوي | إلا جذور المنصات متعددة المستأجرين |
| حساب/متجر على منصة (`salla.sa/store`) | قوي | المسار الأول يحدد المتجر؛ `salla.sa` وحده لا يحدد شيئًا |
| نطاق فرعي لمنصة (`x.myshopify.com`) | قوي | الجذر `myshopify.com` لا يحدد شيئًا |
| السجل التجاري/الموحد (10 أرقام) | قوي | |
| الهاتف | ضعيف | فروع تتشارك الأرقام؛ يُطبّع إلى E.164 فقط عند معرفة الدولة (من الصف أو إعداد workspace) وإلا يبقى «غير مؤكد» |
| الاسم المطبع | ضعيف | تطبيع عربي (همزات، تاء مربوطة، تشكيل، ألفاظ قانونية) |
| نطاق البريد (غير المجاني) | تلميح ضعيف | لا يُعد نطاق الشركة إلا بالمراجعة |

روابط الخرائط والاختصارات لا تُعد معرفًا. البريد: يُخفض النطاق فقط؛ لا تُحذف النقاط أو `+` من الجزء المحلي.

## قواعد القرار

- معرف قوي يطابق شركة واحدة → **ربط** (مع رابط مصدر جديد؛ T06).
- معرفات قوية تشير لأكثر من شركة → **تعارض، لا يُطبق** الصف.
- تطابق ضعيف فقط → إنشاء شركة بحالة **needs_review** + سجل `company_duplicate_candidates` بالأسباب (T07). قرار الدمج/الفصل البشري يُبنى مع شاشة الفرص.
- لا تطابق → إنشاء.
- سجل منع التواصل (`suppressions`، بصمات HMAC) يمنع إعادة الإدخال من أي مصدر، ولا تُحفظ بيانات الصف المستبعد حتى مؤقتًا.

## الاستيراد

- يحتاج مصدرًا **نشطًا** (أكد المالك سياسة استخدامه وتخزينه).
- CSV: UTF-8 أو Windows-1256، فاصل `,` أو `;` أو Tab، أعمدة عربية أو إنجليزية، حد 2MB و2000 صف. خطأ صف لا يُسقط الملف؛ غياب عمود الاسم خطأ ملف.
- المعاينة لا تنشئ كيانات. الاعتماد **idempotent**، ويعيد المطابقة مع القاعدة الحالية، ويُسلسل عبر advisory lock لكل workspace لمنع سباق إنشاء المعرف القوي نفسه.
- بيانات الصفوف الخام تُحذف (SQL NULL) بعد الاعتماد أو الإلغاء؛ المعاينة تنتهي بعد 24 ساعة.
- جهات الاتصال: القيمة محمية بعدم كشف المخطط؛ القوائم تعرضها مقنّعة؛ أهلية التواصل «غير معروفة» افتراضيًا وتمنع الإرسال (SPEC §13).
