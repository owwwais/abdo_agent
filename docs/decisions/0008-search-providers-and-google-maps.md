# 0008 — مزودو البحث وخرائط Google

التاريخ: 2026-09-24 · الحالة: معتمد

## السياق

المالك طلب خيارًا مجانيًا للبدء، وإضافة خرائط Google للاكتشاف. حالة واجهات البحث الرسمية وقت القرار:

- **Google Custom Search JSON API:** مغلقة أمام العملاء الجدد، وتتوقف في 2027-01-01.
- **Bing Search APIs:** أوقفتها Microsoft في 2025-08-11.
- **كشط صفحات نتائج Google/Bing:** يخالف شروطهما ويُحجب سريعًا. مرفوض (SPEC: لا تجاوز حماية).
- **Brave Search API:** 5$ لكل 1000 طلب، مع رصيد 5$ شهريًا، والبطاقة للتحقق فقط.
- **Tavily:** 1000 رصيد شهريًا مجانًا بلا بطاقة. البحث الأساسي = رصيد واحد.

استهلاكنا صغير: 1–3 استعلامات لكل دورة يومية، أي نحو 90 شهريًا. كلا المزودين مجاني فعليًا عند هذا الحجم.

## القرار

1. **مزودان حقيقيان للبحث خلف الواجهة نفسها**: Tavily (المجاني بلا بطاقة) وBrave. الاختيار من الإعدادات.
2. **السعر إلزامي لأي مزود حقيقي، والصفر مقبول.** لا يُرسل طلب بتكلفة غير معروفة؛ اكتب 0 للخطة المجانية. كل طلب يُسجل في دفتر الاستهلاك مهما كان سعره.
3. **خرائط Google عبر Places API (New) — Text Search مؤشر اكتشاف، لا مصدر بيانات مخزنة.**
   سياسة Google تمنع تخزين محتوى Places (الاسم، العنوان، الهاتف، الموقع) وتستثني معرف المكان place ID وحده. لذلك:
   - نطلب أقل الحقول: `id` و`websiteUri` و`types` و`businessStatus`. `websiteUri` يضع الطلب في فئة Enterprise، وأول 1000 طلب شهريًا مجانية.
   - نخزن `place ID` فقط، كمعرف قوي (`google_place`) يمنع التكرار ويمنع إعادة قراءة الموقع نفسه.
   - رابط الموقع يُستعمل عابرًا لقراءة **موقع المنشأة نفسها** عبر `SafeFetcher`. منه يأتي الاسم والوصف والأدلة، وتُحترم robots.txt.
   - المنشأة بلا موقع خاص (أو بصفحة شبكة اجتماعية فقط) أو المغلقة **تُعد في سجل التشغيل ولا تُخزن**.
   - رابط Google Maps يُبنى وقت العرض من place ID، ولا يُخزن `googleMapsUri`.

## البدائل المرفوضة

- **تخزين الاسم والهاتف من Places:** يخالف شروط Google صراحة.
- **الاحتفاظ بمحتوى Places 30 يومًا:** الاستثناء الزمني في الشروط يخص خطوط الطول والعرض فقط.
- **استعلام Pro بدل Enterprise** (بلا `websiteUri`): أرخص، لكن بلا موقع لا يبقى مصدر مستقل نبني منه السجل.
- **SearXNG ذاتي الاستضافة:** مجاني، لكنه يكشط محركات البحث نفسها فيرث مخالفة شروطها، ويحتاج خادمًا إضافيًا.

## العواقب

- منشآت كثيرة صغيرة لها خريطة وهاتف فقط بلا موقع. هذه لا يلتقطها المسار الآلي، ويبقى إدخالها يدويًا. سجل التشغيل يذكر عددها في كل دورة.
- كل منشأة مقبولة تكلف طلب صفحة من موقعها أثناء الاكتشاف (حتى 5 بالتوازي، 15 ثانية لكل موقع). هذا يحتاج `SOURCE_FETCH_ENABLED`.

## المراجع الرسمية

- [Text Search (New)](https://developers.google.com/maps/documentation/places/web-service/text-search): الطلب، وقناع الحقول، وفئات الفوترة.
- [سياسات Places API](https://developers.google.com/maps/documentation/places/web-service/policies): استثناء place ID من قيود التخزين.
- [Places API usage and billing](https://developers.google.com/maps/documentation/places/web-service/usage-and-billing).
- [Tavily Search endpoint](https://docs.tavily.com/documentation/api-reference/endpoint/search) و[Brave Search API](https://brave.com/search/api/).
- [Custom Search JSON API](https://developers.google.com/custom-search/v1/overview): إعلان الإغلاق.
