# 0004 — المصادر والموصلات وحماية الجلب

التاريخ: 2026-09-22 · الحالة: معتمد · F-004، SPEC §5

## أنواع المصادر → الموصلات

| النوع | الموصل | الشبكة |
|---|---|---|
| مقابلات وإحالات، LinkedIn | `manual` | لا اتصال أبدًا. LinkedIn: رابط مرجعي على linkedin.com فقط، لا جلب ولا تسجيل دخول |
| موقع/دليل HTML، بوابة فرص | `html` | قارئ محدود للنطاقات والمسارات المسموحة |
| RSS/Atom | `rss` | تحليل عبر defusedxml |
| بحث ويب | `fake_search` عند `SEARCH_PROVIDER=fake`، وإلا `search:<provider>` | FakeSearch اصطناعي موسوم؛ المزود الحقيقي غير منفذ → needs_setup |
| Google Maps | `google_maps` | غير مفعل → needs_setup مع الخطوة التالية |

لا يُفترض API عام لأي منصة، ولا تُنتج نتائج وهمية عند تعذر الوصول.

## دورة الحالة

`new → validating → sample_ready → active` أو `needs_setup / restricted / failed / paused`.
- الفحص **مهمة في الطابور** (لا اتصال شبكي داخل طلب الويب).
- التفعيل يحتاج: عينة ناجحة **لإصدار الإعداد الحالي** + تأكيد المالك لقائمة سياسة الاستخدام والتخزين (`SOURCE_POLICY_VERSION`)؛ رفع نسخة القائمة يلزم إعادة التأكيد.
- تغيير الرابط/النطاقات/المسارات/الحدود/التخزين/مرجع السر يعيد المصدر إلى `new` ويلغي التأكيد.
- فشل فحص لاحق لمصدر نشط يعطله وحده (`failed`/`restricted`) دون تعطيل النظام.

## حماية الجلب (SSRF)

- http/https فقط؛ رفض userinfo والمنافذ غير 80/443 والأسماء الداخلية (`localhost`، `.internal`…) وعناوين IP غير العامة بكل صيغها (عشرية/ست عشرية/مختصرة، IPv4-mapped، 6to4، NAT64، Teredo).
- حل DNS ثم رفض إن كان **أي** عنوان غير عام، و**الاتصال بالعنوان المفحوص نفسه** مع `Host` وSNI للاسم الأصلي (منع DNS rebinding)، وإعادة كل ذلك عند كل تحويل (حد 3).
- حدود: الطلبات لكل فحص، 2MB بعد فك الضغط، مهلة اتصال/قراءة ومهلة كلية، أنواع محتوى نصية فقط، لا JavaScript، `trust_env=False` (لا بروكسي من البيئة).
- **robots.txt** وفق RFC 9309 (4xx = لا قيود، 5xx = منع) كشرط لازم **وليس ترخيصًا**؛ الترخيص في تأكيد المالك.
- عند النشر: يفضّل ضبط egress على مستوى الشبكة إن أتاحته الاستضافة.

## التخزين

- يُحفظ من العينة ملخص الحقول المستخرجة فقط (≤300 حرف للقيمة) دون HTML خام، مع `expires_at` = 30 يومًا للفحوص (مهمة التنظيف في M5).
- `store_raw` افتراضيًا false؛ مدة الاحتفاظ لكل مصدر.
- التكلفة: جلب HTTP المباشر = 0 معروف؛ `null` = غير معروف (لا تُختلق).
