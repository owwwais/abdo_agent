# دليل المصادر: ماذا تُدخل في كل خانة

المصدر هو **المكان الذي يبحث فيه الوكيل عن الشركات**. كل مصدر يُربط بفئة أو أكثر، والفئة مربوطة بمنتجاتك. في كل صباح يختار الوكيل تركيبة «منتج × فئة × مصدر» ويبحث بها.

## 1) اختر النوع أولًا

| النوع | متى تختاره | يحتاج رابطًا؟ | أين مفتاحه |
|---|---|---|---|
| **خرائط Google (Places API)** | منشآت محلية بالنشاط والمدينة: عيادات، صالونات، مكاتب عقار | لا | الإعدادات ← البحث ← خرائط Google |
| **بحث ويب** | منشآت تذكر في مواقعها ما يدل على حاجتها | لا | الإعدادات ← البحث (Tavily أو Brave) |
| **موقع منشأة أو دليل HTML عام** | دليل عام يسرد منشآت (غرفة تجارية، جمعية مهنية) ويسمح بالقراءة | نعم | لا يحتاج |
| **تغذية RSS/Atom** | موقع ينشر قائمة محدثة بصيغة RSS | نعم | لا يحتاج |
| **بوابة فرص** | صفحة عامة لمنافسات أو فرص (المحتوى العام فقط) | نعم | لا يحتاج |
| **مقابلات وإحالات** | جهات تعرفها أنت، أو تصلك بإحالة | لا | تُضاف من «الاستيراد» يدويًا أو بـCSV |
| **LinkedIn (يدوي)** | جهات وجدتها بنفسك في LinkedIn | لا | يدوي فقط؛ لا دخول آلي |

## 2) الخانات

**لخرائط Google وبحث الويب يكفي: الاسم + النوع + الفئات. اترك الباقي على قيمه الافتراضية.**

| الخانة | ماذا تكتب | متى تهم |
|---|---|---|
| **الاسم** | اسم تعرفه أنت، مثل «خرائط Google» أو «دليل الغرفة التجارية» | دائمًا |
| **النوع** | من الجدول أعلاه | دائمًا |
| **الفئات المستهدفة** | علّم كل فئة يصلح لها هذا المصدر. **مصدر بلا فئة لا يُستخدم أبدًا** | دائمًا |
| **الرابط** | رابط الصفحة التي تبدأ منها القراءة، مثل صفحة قائمة الدليل | HTML وRSS والبوابات فقط |
| **النطاقات المسموحة** | اتركه فارغًا (يُملأ تلقائيًا من الرابط). أضف نطاقًا فقط إن كانت صفحات التفاصيل على نطاق فرعي آخر | HTML فقط |
| **المسارات المسموحة** | بداية روابط صفحات المنشآت داخل الدليل، مثل `/company/` أو `/members/`. **فارغ يعني: موقع منشأة واحدة لا دليل** | أدلة HTML فقط |
| **حد الصفحات** | كم صفحة يقرأ في كل مرة (3 افتراضيًا). للأدلة الكبيرة 10–20 | HTML |
| **حد السجلات** | حجم العينة عند «فحص عينة» (5). لا يغير عدد نتائج الاكتشاف اليومي | كل الأنواع |
| **حد الطلبات** | سقف أمان لعدد الطلبات للموقع في المرة الواحدة (6) | HTML وRSS |
| **المهلة (ثانية)** | 60 مناسبة؛ ارفعها للمواقع البطيئة | HTML وRSS |
| **فترة التحديث (ساعة)** | **لا تؤثر حاليًا**: الاكتشاف يعمل مرة يوميًا مهما كانت قيمتها | — |
| **مدة الاحتفاظ (يوم)** | كم يومًا تبقى الأدلة المأخوذة من هذا المصدر (90) | كل الأنواع |
| **مرجع السر** | **اتركه فارغًا.** مفاتيح Tavily وBrave وGoogle تُدخل في الإعدادات ← البحث | — |
| **حفظ المحتوى الخام** | اتركه **غير معلّم**. نحفظ الحقول المستخرجة فقط | HTML |
| **ملاحظات السياسة** | سطر يذكّرك لماذا المصدر مسموح، مثل «واجهة رسمية بمفتاحي» أو «شروط الدليل تسمح بالقراءة العامة» | اختياري |

## 3) خطوات إضافة مصدر

1. **المصادر ← مصدر جديد**: اكتب الاسم واختر النوع وعلّم الفئات ← حفظ.
2. **فحص عينة**: يعمل في الخلفية دقيقة تقريبًا، ثم أعد تحميل الصفحة.
3. **راجع العينة**:
   - **خرائط Google:** كم مكانًا وجد، وكم منها له موقع إلكتروني.
   - **بحث ويب:** عناوين النتائج.
   - **الأدلة:** هل التقط الأسماء والروابط الصحيحة.
4. **علّم البنود الثلاثة، ثم «تأكيد وتفعيل المصدر»**:
   - شروط المصدر تسمح بهذا الاستخدام.
   - لا تسجيل دخول ولا تجاوز حماية.
   - مدة الاحتفاظ مناسبة.

   هذا تأكيدك أنت، والوكيل لا يفعّل مصدرًا بنفسه.
5. **إن عدّلت إعداد مصدر مفعل** (الرابط أو الحدود)، يعود «جديدًا» ويحتاج فحصًا وتأكيدًا من جديد.

## 4) أمثلة جاهزة

**خرائط Google**
- الاسم: `خرائط Google`
- النوع: خرائط Google (Places API)
- الفئات: كلها
- الباقي افتراضي.

الوكيل يكتب الاستعلامات بنفسه من الفئة والمدينة، مثل «عيادة أسنان الرياض».

**بحث ويب**
- الاسم: `بحث ويب`
- النوع: بحث ويب
- الفئات: كلها
- الباقي افتراضي.

يلتقط منشآت تذكر في صفحاتها ما يدل على حاجتها، مثل «الحجز عبر الهاتف».

**دليل عام** (مثال افتراضي)
- الاسم: `دليل الغرفة التجارية`
- النوع: موقع منشأة أو دليل HTML عام
- الرابط: `https://directory.example/members`
- المسارات المسموحة: `/members/`
- حد الصفحات: 10
- الفئات: ما يناسب الدليل.

قبل التفعيل اقرأ شروط الموقع. إن طلب تسجيل دخول أو منع الجمع، فاستخدم الإدخال اليدوي بدله.

## 5) أخطاء شائعة

| ما يحدث | السبب | الحل |
|---|---|---|
| الاكتشاف يقول «لا يوجد منتج نشط بفئة نشطة ومصدر نشط» | المصدر غير مفعل، أو غير مربوط بفئة منتج مفعل | فعّل المصدر، وتأكد أن فئته مربوطة بمنتج مفعل |
| فحص العينة «يحتاج إعدادًا» | مفتاح الخدمة غير مدخل، أو السعر فارغ | الإعدادات ← البحث: المفتاح والسعر (0 للخطط المجانية) |
| خرائط Google تجد أماكن لكن «0 بموقع قُرئ» | المنشآت بلا مواقع إلكترونية | طبيعي لبعض الأنشطة؛ جرّب نشاطًا أو مدينة أخرى |
| دليل HTML يعيد صفحة واحدة فقط | المسارات المسموحة فارغة | اكتب بداية روابط صفحات المنشآت في الدليل |
| «مقيّد»: robots.txt يمنع، أو الصفحة تطلب دخولًا | الموقع لا يسمح بالقراءة الآلية | لا تتجاوزه؛ أضف جهاته يدويًا من «الاستيراد» |

للمنصات الأخرى (LinkedIn، Instagram، متاجر…) وأيها يصلح آليًا: [adding-sources.md](adding-sources.md).
