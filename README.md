# وكيل البحث والمبيعات

نظام داخلي للمؤسسين يجد عملاء محتملين بأدلة موثقة، ويكتب رسالة أولى، **ولا يرسل شيئًا قبل اعتمادك**، ثم يتابع الردود. المواصفة في [SPEC.md](SPEC.md)، وحالة البناء في [harness/handoff.md](harness/handoff.md).

> **الحالة: الدورة كاملة ومختبرة محليًا بموصلات اصطناعية.** 180 اختبارًا ناجحًا. لم يُستدعَ أي مزود حقيقي ولم تُرسل أي رسالة لأي جهة، و`OUTBOUND_ENABLED=false`.
>
> **للإطلاق الحقيقي اتبع [دليل التشغيل والإطلاق](docs/runbooks/launch-guide.md):** من أين تحصل على كل مفتاح، وأين يوضع، ومثال متكامل.

## الدورة

اكتشاف يومي محدود ← تأهيل من الأدلة فقط (0–100) ← مسودة تمر بفحص سياسة ← **اعتمادك** من اللوحة أو تيليجرام ← إرسال من بريدك عبر SMTP ← قراءة الرد وربطه وتصنيفه ← رد مقترح يحتاج اعتمادًا أيضًا. كل خطوة محكومة بحصة يومية وميزانية وسجل تدقيق.

## المتطلبات

- [uv](https://docs.astral.sh/uv/) (يثبت Python 3.12 تلقائيًا).
- PostgreSQL 16: إما السكربت المحلي (بلا Docker) أو `docker compose up db`.

## التشغيل المحلي

```bash
cp .env.example .env            # ثم عدّل APP_ENV=development إن أردت تجربة جلب مواقع حقيقية
uv sync
uv run python scripts/localdb.py start
uv run alembic upgrade head
uv run python scripts/seed_demo.py
uv run python -m app.main        # الواجهة على http://127.0.0.1:8000
uv run python -m app.jobs.worker # في طرفية ثانية: البحث والإرسال والمزامنة والمجدول
```

أو كل ذلك معًا: `scripts/dev.sh` (Git Bash/Linux/macOS).

ادخل من `/login` بزر «مالك تجريبي» (fixture محلي يعمل فقط في البيئات المحلية ومن الجهاز نفسه). جرّب الدورة كاملة:

1. **المنتجات** → «[تجريبي] منظم المواعيد» → تفعيل، ثم «اختبر فهم النموذج للمنتج».
2. **المصادر** → «بحث ويب» → فحص عينة → أكّد بنود السياسة → تفعيل.
3. **التشغيل** → «دورة اكتشاف اليوم» ثم «معالجة فرصة واحدة».
4. **الفرص** → افتح الفرصة المؤهلة → الشركة → «إضافة جهة اتصال يدويًا» → عد للفرصة → «معالجة الآن».
5. **الموافقات** → وثّق أهلية التواصل بسند → «اعتماد وإرسال» (إرسال اصطناعي في هذه البيئة).
6. **الاستيراد** → أدخل جهة أو ارفع CSV لتجربة إزالة التكرار.

## الاختبارات والفحوص

```bash
uv run pytest -q                 # 180 اختبارًا: وحدة + تكامل + مسار HTML + E2E بمتصفح
scripts/check.sh                 # ruff + format + mypy + pytest
harness/run.sh quick             # فحص سريع بلا قاعدة
```

الاختبارات تستخدم قاعدة `sales_test` (أو `TEST_DATABASE_URL`) وتعيد بناءها من الترحيلات في كل تشغيل. لا تحتاج شبكة خارجية: الجلب يُختبر بشبكة اصطناعية (`tests/fakes.py`).

## البنية

```
app/agents     بوابة النماذج (Anthropic/OpenAI/متوافق/Gemini)، المخططات الصارمة، التعليمات
app/workflows  الاكتشاف ورسم الفرصة (LangGraph بحفظ دائم) وقفل المعالجة
app/api        JSON API، الويب هوك، الأخطاء، التحقق من الجلسة وCSRF
app/auth       Supabase Auth (JWKS)، جلسات الخادم، fixture التطوير
app/connectors عقد الموصلات، جالب HTTP آمن (SSRF)، HTML/RSS، FakeSearch، اليدوي
app/services   المنتجات والمصادر والاستيراد، الاعتماد والإرسال والوارد، الميزانية والحصص،
               الإعدادات والأسرار المشفرة، تيليجرام، الملخص والتنظيف
app/jobs       طابور PostgreSQL والعامل ومعالجات المهام
app/web        صفحات HTML العربية
app/db         النماذج والجلسة
migrations     ترحيلات Alembic مرحلية (0001 = M0، 0002 = M1، 0003 = الدورة)
evals          حالات تقييم النموذج الاصطناعية
harness        سجل الخصائص والتقدم والتسليم للوكيل البرمجي
docs           القرارات، أدلة التشغيل، تقارير التحقق
```

## الإعداد

مفاتيح البنية (القاعدة وSupabase والأسرار الداخلية ومفتاح الإيقاف العام) في [.env](.env.example). مفاتيح التكاملات (النماذج، البريد، البحث، تيليجرام) من **صفحة الإعدادات** داخل التطبيق: تُحفظ مشفرة، وتتقدم على ملف البيئة، ولا تُعرض بعد الحفظ.

خارج `demo/development/test` يرفض التطبيق الإقلاع دون: `SESSION_SECRET` و`DATA_HASH_KEY` (32+ حرفًا)، ومفتاح Fernet صالح، وSupabase، وhttps؛ ويرفض `DEV_AUTH_ENABLED`. بيئة `demo` تفرض موصلات اصطناعية وتمنع الإرسال.

## أدوات التشغيل

```bash
uv run python scripts/gen_secrets.py        # يولّد الأسرار الداخلية في .env
uv run python scripts/backup.py dump        # نسخة احتياطية، وverify يختبر الاسترجاع فعليًا
uv run python scripts/eval_models.py --yes  # تقييم النموذج على 30 حالة موسومة قبل اعتماده
uv run python scripts/add_member.py ...     # ربط حساب Supabase بعضوية
```
